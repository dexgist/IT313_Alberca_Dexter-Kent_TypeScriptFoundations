# IT313 TypeScript Foundations

## Project Title

Enrollment Eligibility Checker - TypeScript

## Student Information

Name: Dexter Kent G. Alberca
Section: BSIT 3A
Subject: IT313 - Mobile Programming

## Project Description

This project is a TypeScript version of the Enrollment Eligibility Checker created in Laboratory 2.

The program calculates student averages and determines whether each student is PASSING or PROBATION.

## TypeScript Concepts Used

1. Basic Type Annotations
2. Interfaces
3. Enums
4. Optional Properties
5. Union Types
6. Generics
7. Promises and Async/Await
8. Map, Reduce, and Template Literals

## Files

- gradeUtils.ts - Contains average and status functions.
- main.ts - Contains the main program and enrollment data.
- tsconfig.json - TypeScript configuration.
- README.md - Project documentation.

## How to Run

Install dependencies:

npm install

Type-check the program:

npx tsc --noEmit

Run the program:

npm start

## Expected Result

The program displays the average, status, and remarks of each enrollee.

## Conclusion

TypeScript helps identify type-related errors before the program runs. It makes the code more organized and prepares developers for using typed props and state in React Native.
